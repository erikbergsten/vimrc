# all the configs

its everything

## tmux config

install by creating a symlink

```
ln -s $PWD/tmux.conf ~/.config/tmux/tmux.conf
```


## init.vim

important features:

- rendering whitespaces (tabs, trailing spaces and newlines)
- color columns
- many nice bindings

install by creating as symlink

```
ln -s $PWD/init.vim ~/.config/nvim/init.vim
```
